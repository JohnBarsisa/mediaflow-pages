# MediaFlow beta test site

This repository publishes the static MediaFlow frontend to [GitHub Pages](https://johnbarsisa.github.io/mediaflow-pages/). The API runs on Render and still requires the private beta access code. Never commit the access code, private media, or browser session data here.

The full application and development history are maintained in the private MediaFlow repository. This snapshot was taken from its `main` commit `18e1ecfd9aaef0986e40aa0436d9dcc30b71b232`. To update this site, copy the current browser assets from the private repository's `frontend/` directory and keep the home link relative for the Pages project path. GitHub Pages serves the root of `main`.
